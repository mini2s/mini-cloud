## 迁移老项目 usage 页面 → 个人中心-我的配额

把 `https://zgsm.sangfor.com/cloud/console/usage`(用量统计:配额概览 + 用量消耗)1:1 移植到当前项目已存在但为占位符的 `/{slug}/me/quota` 路由。

---

### 架构方案(完全复刻现有 Hub 代理模式)

老页面调用外部 `quota-manager` 服务的两个接口(`/quota-manager/api/v1/quota`、`/quota-manager/api/v1/usage/statistics`),与 Hub 模块调用外部 capability 后端的情况完全一致。因此采用**相同的 Go 反向代理模式**:前端走相对路径 `/api/quota-manager/*` → Go server 透明转发到外部 `QUOTA_MANAGER_API_BASE_URL`,沿用浏览器 session(及 dev token)鉴权,绕开 mini-cloud 的 Auth 中间件。

用户已确认:日期范围用 **Calendar(mode=range)+Popover** 还原老版本日历体验;配额进度条用 **@multica/ui 主题色 Progress 组件**(不复刻老版蓝绿渐变)。

---

### 1. 后端 Go — 反向代理(克隆 hub_proxy.go)

**新建** `server/internal/handler/quota_manager_proxy.go`
- 完全克隆 `hub_proxy.go` 的 `httputil.ReverseProxy` 结构:`Director` 把 `req.URL.Path`(原 `/api/quota-manager/...`)前拼 `h.cfg.QuotaManagerAPIBaseURL`;`devToken`(`HUB_DEV_TOKEN`)注入 `zgsmAdminToken` cookie + Bearer;`ModifyResponse` 剥离上游 CORS 头;`ErrorHandler` 返回 502。
- 导出 `(h *Handler) QuotaManagerProxy() http.HandlerFunc`,未配置时返回 `nil`。

**改** `server/internal/handler/handler.go`
- 在 `Config` 里 `BuiltinPluginAPIBaseURL` 旁新增 `QuotaManagerAPIBaseURL string`。

**改** `server/cmd/server/router.go`
- 第 201 行旁加:`QuotaManagerAPIBaseURL: strings.TrimRight(strings.TrimSpace(os.Getenv("QUOTA_MANAGER_API_BASE_URL")), "/")`
- 在 Hub 代理块(386–412)之后,同样**位于 auth group 之外**,挂载:`r.MethodFunc(GET, "/api/quota-manager/*", quotaProxy)`(GET 足够,两接口都是 GET)。
